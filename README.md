# Next Level Assignment 1 – TypeScript

## 📌 Assignment সম্পর্কে

এই Repository-তে আমার Next Level Assignment 1-এর কাজগুলো রাখা হয়েছে। এখানে আমি মোট ৮টি TypeScript Problem সমাধান করেছি এবং TypeScript-এর গুরুত্বপূর্ণ কিছু বিষয় নিয়ে দুটি Technical Blog লিখেছি।

প্রতিটি Problem সমাধান করার সময় শুধু কোড লেখার চেষ্টা করিনি, বরং কোন জায়গায় কোন Type ব্যবহার করতে হয় এবং কেন ব্যবহার করতে হয়, সেটাও বোঝার চেষ্টা করেছি।

## 💻 ৮টি Problem সমাধান করতে যা যা ব্যবহার করেছি

### 1. Functions

- Function তৈরি করা এবং Parameter ব্যবহার করা।
- Function-এর Return Type নির্ধারণ করা।
- Function কীভাবে Input গ্রহণ করে এবং Output দেয় তা বোঝা।

### 2. Arrays and Objects

- Array-এর মধ্যে একাধিক Data রাখা।
- Object তৈরি করা এবং তার Property নির্ধারণ করা।
- Array of Objects নিয়ে কাজ করা।
- Object-এর Property Access করা।

### 3. Tuple

- Tuple তৈরি করা এবং নির্দিষ্ট Data Type ব্যবহার করা।
- Tuple-এর প্রতিটি Position-এ কোন Type-এর Value থাকবে তা নির্ধারণ করা।
- Array এবং Tuple-এর পার্থক্য বোঝা।

### 4. Union Types and Type Narrowing

- একটি Variable-এ একাধিক Type ব্যবহার করা।
- `string | number | boolean` দিয়ে Union Type তৈরি করা।
- `typeof` ব্যবহার করে Value-এর Type Check করা।
- Condition অনুযায়ী সঠিক Operation করা।

### 5. Generics

- Generic Function তৈরি করা।
- Function-এর মাধ্যমে বিভিন্ন Type-এর Data নিয়ে কাজ করা।
- `T` ব্যবহার করে Reusable এবং Type-safe Function তৈরি করা।
- Generic Function-এর Parameter এবং Return Type বোঝা।

### 6. Type Aliases, Interfaces and Type Hierarchy

- `type` দিয়ে Custom Type তৈরি করা।
- `interface` দিয়ে Object-এর Structure নির্ধারণ করা।
- Type Alias এবং Interface-এর পার্থক্য বোঝা।
- `any`, `unknown` এবং `never` Type সম্পর্কে শেখা।

### 7. Classes and Inheritance

- Class এবং Constructor তৈরি করা।
- `extends` ব্যবহার করে Inheritance করা।
- `super()` দিয়ে Parent Class-এর Constructor Call করা।
- `public`, `private` এবং `protected` Access Modifier ব্যবহার করা।
- Parent এবং Child Class-এর মধ্যে সম্পর্ক বোঝা।

### 8. Promise and Asynchronous Programming

- `Promise` ব্যবহার করে Asynchronous Function তৈরি করা।
- `resolve()` এবং `reject()` ব্যবহার করা।
- `setTimeout()` দিয়ে নির্দিষ্ট সময় পর কাজ সম্পন্ন করা।
- `Error` ব্যবহার করে Error Handle করা।
- `async` এবং `await` সম্পর্কে ধারণা নেওয়া।

## 🎯 এই Assignment থেকে যা শিখেছি

এই Assignment করার মাধ্যমে TypeScript সম্পর্কে আমার ধারণা আরও পরিষ্কার হয়েছে। বিশেষ করে JavaScript-এর সাধারণ Function, Array এবং Object-এর পাশাপাশি TypeScript-এ কীভাবে Type নির্ধারণ করতে হয়, সেটা শিখেছি।

আগে Union Type, Generics, Tuple কিংবা Access Modifiers-এর মতো বিষয়গুলো কিছুটা কঠিন মনে হতো। কিন্তু নিজে কোড লিখে এবং বিভিন্ন Error ঠিক করার মাধ্যমে বিষয়গুলো ভালোভাবে বুঝতে পেরেছি।

এছাড়া বুঝতে পেরেছি TypeScript শুধু Code-এর Error ধরার জন্য নয়, বরং Code-কে আরও Organized, Reusable এবং Type-safe করতেও সাহায্য করে।

এটি আমার TypeScript শেখার একটি গুরুত্বপূর্ণ অনুশীলন। সামনে আরও ভালোভাবে TypeScript শেখার এবং বাস্তব Project-এ এসব Concept ব্যবহার করার চেষ্টা করব।
